# 智慧社区设备设施全生命周期管理系统

对社区内的 **电梯、消防、水泵、门禁** 等设备设施进行 **台账管理、巡检保养、维修工单、维保合同、运行监测、年限分析** 的全生命周期管理系统。前后端分离，含 **PC 管理端** 与 **移动端扫码巡检 H5**。

## ✨ 核心功能

| 模块 | 说明 |
| --- | --- |
| 🗂 设备台账 | 设备建档（编号/类型/位置/厂家/安装日期/使用年限/保修期），二维码标签生成与下载 |
| 📋 巡检/保养计划 | 按设备巡检周期/保养周期 **自动生成** 未来计划，逾期自动标记，完成率统计 |
| 📱 移动端扫码打卡 | 摄像头扫码或输入编号，快速完成巡检打卡，异常结果自动提示报修 |
| 🔧 报修工单 | 报修登记 → 派单 → 维修 → 验收 全流程流转，费用统计，维修完成联动设备状态 |
| 📄 维保合同 | 合同管理 + **到期自动提醒**（30 天内到期 / 已过期红色预警） |
| 📡 运行监测 | 设备实时状态大屏（温度/振动/电压/健康度），5 秒轮询，异常告警 |
| 📊 年限分析 | 使用年限分布、安装年份统计、**超期服役设备清单**与更换建议 |
| 👥 权限管理 | 系统管理员 / 维保人员 / 巡检人员 三种角色，JWT 登录认证 |

## 🛠 技术栈

- **后端**：Spring Boot 2.7.18 · MyBatis-Plus 3.5.3 · MySQL 8.0 · JWT (jjwt) · ZXing 二维码 · Maven
- **前端**：Vue 3 · Vite 5 · Element Plus · ECharts 5 · Pinia · Vue Router · Axios · html5-qrcode
- **移动端**：同一前端工程的 `/mobile/*` 路由，响应式适配手机

## 🚀 快速启动

### 0. 环境要求
- JDK 1.8、Maven 3.8（本地仓库 `D:\maven-repository`）、Node.js 16+、MySQL 8.0

### 1. 初始化数据库

```bash
mysql -uroot -p123456 --default-character-set=utf8mb4 < database\smart_community.sql
```

> 若数据库密码不是 `123456`，请同步修改 `backend/src/main/resources/application.yml` 中的 `spring.datasource.password`。

### 2. 启动后端（端口 8080）

```bash
java -jar backend\target\smart-community.jar
```

或源码运行：

```bash
cd backend
mvn -Dmaven.repo.local=D:\maven-repository spring-boot:run
```

### 3. 启动前端（端口 5173）

```bash
cd frontend
npm install
npm run dev
```

浏览器访问 **http://localhost:5173**（已配置代理转发 `/api` 到 8080）。

### 4. 移动端巡检

手机与电脑同一局域网，访问 `http://<电脑IP>:5173/mobile/scan`。
设备二维码内容指向 `http://172.20.10.5:5173/mobile/scan?code=设备编号`（当前使用手机热点，电脑 IP 为 172.20.10.5；更换网络后请在 `application.yml` 的 `smart.qr.base-url` 与 `database/gen_seed.py` 的 `QR_BASE` 同步修改为新的电脑局域网 IP，并重新打包、重新导入 SQL）。
> 摄像头扫码要求 **HTTPS 或 localhost** 环境；局域网 HTTP 下请使用「输入编号」模式，功能一致。
